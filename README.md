# Amigo Secreto - Sorteo

Este proyecto es una aplicación web simple para realizar un sorteo de "Amigo Secreto". Los usuarios pueden agregar nombres de amigos, y la aplicación seleccionará aleatoriamente un ganador del grupo.

## Características

- Los usuarios pueden agregar nombres a la lista de amigos.
- La aplicación sortea aleatoriamente un ganador de entre todos los nombres agregados.
- Se muestra el ganador en la página.
- Se permite limpiar la lista de amigos y reiniciar el sorteo.

## Tecnologías

- **Lenguajes:** JavaScript, HTML, CSS

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/JonasRivadeneyra/challenge-amigo-secreto.git
   
Uso

    Ingresa el nombre de un amigo en el campo de texto y presiona "Agregar".
    Los nombres agregados se muestran en una lista en la página.
    Para realizar un sorteo, presiona el botón Sorteo. La aplicación elegirá aleatoriamente a un ganador.
    Si deseas limpiar la lista y reiniciar el proceso, presiona Nuevo sorteo.

Funcionalidad

    Agregar un amigo: Al escribir un nombre y presionar "Agregar", el nombre se agrega a la lista de amigos. Si el nombre ya está en la lista o si está vacío, la aplicación muestra una alerta.
    Sorteo: Cuando presionas el botón "Sorteo", la aplicación elige un ganador al azar y lo muestra en la sección de resultados.
    Limpiar lista: La lista de amigos y el campo de texto se limpian al hacer un nuevo sorteo.
